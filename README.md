# Rafael Arenas — Portfolio

Personal developer portfolio for Rafael Arenas (Full Stack Developer), built as a terminal-themed single-page app.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- No backend — static build, bilingual (ES/EN) content, live project data from the GitHub API

## Development

```bash
npm install
npm run dev     # http://localhost:4927
npm run build
```

## Branching

`main` is protected (no direct pushes, no force-push). Work happens on feature branches merged through pull requests.
